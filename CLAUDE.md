# Development conventions

Keep graph and release queries explicit. Preserve deterministic ordering in retrieval, as candidate order affects the recorded request keys. Treat the fictional source documents, structured graph and authored case expectations as a single dataset.

The public edition runs only in replay. Do not substitute newly written prose for a recorded model response. Recordings include exact inputs and response text. Keep personal data, real confidential material and credentials out of the source and fixtures.

Run the full Compose replay suite against its separate test database after behavioral changes. Inspect the final walkthrough and PDF whenever the corpus, verification rules or display changes.

# Working with the source

This repository is a portfolio publication. Before proposing a change, contact the portfolio owner through the About page linked in the README. Keep real client data, confidential documents, personal information and credentials out of all files, including tests and fixtures.

Use a separate Compose project for testing. Run `docker compose run --rm app pytest` and check that all authored gold, baseline and intake cases ran. Preserve original recording keys. Document any changes to evidence, case expectations or screenshots.

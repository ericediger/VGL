# Demonstration guide

Start in the static overview for a short captioned video, the illustrated PDF and the full walkthrough. All assets are included in the website directory.

In the walkthrough use left/right or the buttons to move. Number keys select a section. R returns to its start, F opens a record on a case step and ? shows the keys. Escape closes a dialog. The evidence section provides all 13 records, including the separate document baseline. Every displayed result comes from replay. The browser never connects to the database.

The local application runs the same request-keyed recorded steps plus the actual retrieval, verifier and change workflow. The **Compare** tab presents the document baseline, which lacks the separate place and date inputs. The **Releases** tab makes the ruling and amendment available in sequence. The **Issued answers** tab shows the effective date at which a cited definition is superseded.

The example identifiers in the interface map to `data/gold.yaml`. The report in this repository records a complete replay of the final inputs. Historical model names identify the fixture keys. No model service is used by this edition.

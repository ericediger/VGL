# Limits of the evidence

- A structurally valid citation can accompany an incorrect interpretation. The summary can retain claims removed from the structured list. Open the evidence and review the retained claims and flags.
- Retrieval starts from selected concepts and stops at a depth limit. A missing source or unrecorded relationship can go undetected. A known referenced gap can trigger review.
- The secondary model's saved judgments are advisory. Missing or incomplete verdicts can leave a claim unflagged. Calibration and independence have not been established.
- The authored gold set is small and was used during development. Its passing rate measures those expectations. The question-only baseline uses different controls.
- Stored answer rows include the question, frame, packet, structured claims, flags and verification details. Some presentation fields, including the free-text summary, are omitted. The issued-answer register separately stores its own text and version references. Reproducing evidence requires compatible data, code and schema.
- The website plays a fixed demonstration. Local editor actions change one local database. The mutation routes lack application authentication. Run only the local Compose configuration.
